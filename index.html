Built For True Disaster Realities

Based on Implementation Plan Revision 3 — Engineering that works without cell towers.

⚡

3-Tap Emergency SOS

Under extreme panic and physical confinement, complex typing fails. MESHLiNE features high-contrast 56+ dp targets: tap SOS, pick a category (Medical, Trapped, Fire), and broadcast automatically with GPS and battery status.

🔁

Multi-Hop Store-Carry-Forward

Messages hop across peer devices via Bluetooth and Wi-Fi Direct. If nodes move or become disconnected, messages are stored locally and forwarded the instant a new peer appears.

🧭

Breadcrumb Rescuer ACKs

Unlike naive flooding protocols that saturate radio channels, MESHLiNE records incoming node breadcrumbs. Rescuer confirmations follow the exact reverse path back to the trapped victim, ending with “Received by Rescuer”.

🔒

Ed25519 & Sybil Defense

Every packet is signed with Ed25519 cryptography, verified with a 64-bit anti-replay sliding window, and throttled by strict per-link rate limits to thwart attackers with rogue transmitters.

⚠

Emergency Beats Authenticity

If phone cryptographic storage fails during a disaster, human life comes first: an SOS is still broadcast with an UNVERIFIABLE flag, displayed with a signature dashed brass badge, and rate-limited to prevent abuse.

🔋

Battery-Aware Duty Cycles

Three operating tiers (Normal, Saver, and Critical) conserve battery life over days of blackout, concluding with a low-power last-gasp beacon below 5% charge.

Protocol & Security Specifications

Complete alignment with Revision 3 implementation rules.

Specification Standard Implementation Rationale
Packet Format Binary / Protobuf Schema (≤ 8 KB) Compact size fits high-throughput BLE / Wi-Fi peer links.
Cryptography Ed25519 Elliptic Curve Signatures All immutable fields signed; node ID = SHA-256 public key hash.
Anti-Replay Window 64-bit Sliding Bitmap Discards replayed packets without requiring synchronized real-time clocks.
Sybil Attack Defense Physical Link Rate Limiting (60/min) Restricts malicious nodes from flooding the mesh with forged identities.
ACK Forwarding Targeted Breadcrumb Return Halves network congestion compared to generic flooding protocols.
Clock Skew Tolerance 24-Hour Expiry Grace Period Prevents premature packet eviction if phone system clock drifts offline.
